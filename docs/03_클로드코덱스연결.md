# 03. 클로드 코드 · 코덱스 연결

> 클로드 코드(또는 코덱스)에 `studio`·`blender` MCP 를 등록해, 말로 시키면 블렌더가 움직이게 한다.

## 준비물
- 02 문서까지 끝(블렌더 + 애드온 + `studio` 명령)
- 클로드 코드나 코덱스 중 하나 이상

### 클로드 코드 설치(공식)
```bash
curl -fsSL https://claude.ai/install.sh | bash        # 맥·리눅스
irm https://claude.ai/install.ps1 | iex               # 윈도우 PowerShell
```
(또는 `brew install --cask claude-code` / `winget install Anthropic.ClaudeCode`) — 자세한 건 https://code.claude.com/docs/en/setup

### 코덱스 설치(공식)
```bash
npm install -g @openai/codex          # 또는 맥: brew install --cask codex
```

## 단계
설치 스크립트(`install/install_mac.sh` · `install_win.ps1`)가 아래를 대신 한다. 손으로 하려면:

### 클로드 코드
```bash
claude mcp add --scope user studio -- studio serve
claude mcp add --scope user blender -e DISABLE_TELEMETRY=true -- uvx mcp-for-blender
```
- `--scope user` = 모든 폴더에서 쓴다. 이 프로젝트에서만 쓰려면 `--scope project`(→ `.mcp.json` 이 생긴다, 예시: `install/examples/claude_mcp.json`).
- 매번 "이 도구 써도 될까요?"를 묻는 게 번거로우면 클로드 코드 설정의 허용 목록에 `mcp__studio`·`mcp__blender` 를 넣는다.

### 코덱스
```bash
codex mcp add studio -- studio serve
codex mcp add blender --env DISABLE_TELEMETRY=true -- uvx mcp-for-blender
```
또는 `~/.codex/config.toml` 에 직접(예시: `install/examples/codex_config.toml`). 코덱스는 도구 하나에 기본 60초까지만 기다리니, 믹사모 리깅처럼 오래 걸리는 일을 위해 `[mcp_servers.studio]` 아래 `tool_timeout_sec = 600` 이 필요하다. 설치 스크립트는 이걸 `studio codex-config` 로 넣는다 — 원본을 `config.toml.bak-<시각>` 으로 복사한 뒤 그 줄 하나만 끼우고, 이미 값이 있으면 그대로 둔다. 손으로 할 때도:
```bash
studio codex-config            # 결과: changed true/false, backup 경로
```

## 확인
1. 클로드 코드/코덱스를 **완전히 껐다 켠다**(윈도우는 트레이 아이콘까지 종료).
2. `claude mcp list` / `codex mcp list` → `studio`·`blender` 가 연결됨(Connected / enabled)으로 나온다. 클로드 코드 안에서는 `/mcp`.
3. 이렇게 말해 본다:
   - "스튜디오 상태 알려줘" → `studio_status` 가 블렌더·애드온·계정 상태와 남은 할 일을 보여 준다.
   - "자동차 찾아줘" → 스케치팹 추천 8개 썸네일 시트가 나온다(04 문서).
   - "블렌더에 큐브 하나 만들어 줘" → `blender` 서버가 블렌더에 코드를 보낸다.

## 쓸 수 있는 도구(studio)
| 도구 | 하는 일 |
|---|---|
| `studio_status` | 설치·연동 상태 한눈에 |
| `account_signup(service)` · `account_login(service)` · `account_logout(service)` | 스케치팹·믹사모 가입 페이지 열기 / 로그인 창 → 토큰 자동 저장 / 지우기 |
| `sketchfab_search(query, count, max_faces, license, animated, rigged)` | 추천 목록 + 썸네일 시트 이미지 |
| `sketchfab_import(uid, target_size_m, name)` | 받아서 블렌더로(바닥 맞춤·크기·출처 기록) |
| `mixamo_search` · `mixamo_rig` · `mixamo_animate` · `mixamo_list_applied` | 믹사모 동작 검색·자동 리깅·동작 붙이기(05 문서) |
| `blender_ping` · `blender_screenshot` | 연결 확인 · 장면 한 장 |
| `render_plan` · `render_distributed` · `render_job_status` | 맥+윈도우 분산 렌더(06 문서) |
| `triposg_generate` | 그림 한 장 → 3D 모델(07 문서) |

같은 기능을 터미널에서도 쓴다: `studio --help`.

## 자주 막히는 곳
| 증상 | 원인 · 해결 |
|---|---|
| 앱(데스크톱)이 `studio`·`uvx` 를 못 찾는다 | GUI 앱은 터미널 PATH 를 모를 수 있다. 명령을 전체 경로로 등록한다: `which studio` / `which uvx`(윈도우 `where`). |
| 등록했는데 도구가 안 보인다 | 등록 뒤 앱을 완전히 다시 켜야 한다. `claude mcp list` 에서 실패로 나오면 `studio serve` 를 터미널에서 직접 실행해 오류를 본다(Ctrl+C 로 끔). |
| `uvx mcp-for-blender` 를 터미널에서 직접 켰더니 멈춘 것 같다 | 원래 그렇다(MCP 클라이언트의 입력을 기다리는 중). 터미널에서 켜 둘 필요 없다. |
| conda·pyenv 가 있어서 설치가 꼬인다 | MCP 설정 env 에 `UV_PYTHON_PREFERENCE=only-managed`, args 에 `--python 3.11` 을 넣어 uv 가 자기 파이썬을 쓰게 한다. |
| 세션 여러 개가 블렌더 하나를 같이 쓴다 | 세션마다 MCP 서버가 하나씩 떠서 같은 9876 에 붙는다. 블렌더가 명령을 차례로 처리하니 문제없지만, 동시에 같은 물체를 고치면 결과가 섞인다. |
| GUI 블렌더 없이 쓰고 싶다 | 그냥 쓰면 된다. `studio` 는 GUI 가 꺼져 있으면 백그라운드 작업 장면(`~/.blender-mcp-studio/work/scene.blend`)에서 일한다. 결과는 `blender_screenshot` 로 본다. GUI 를 켜 둔 채 강제로 백그라운드를 쓰려면 MCP env 에 `STUDIO_BLENDER_MODE=headless`. |
