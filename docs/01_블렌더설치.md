# 01. 블렌더 설치

> 블렌더 5.2 LTS(장기 지원판)를 깔고, 터미널에서 백그라운드로 돌릴 수 있게 해 둔다.

**한 번에 하려면** — 이 문서의 내용은 설치 스크립트가 다 한다(01~03단계 + 로그인 창 브라우저).

```bash
bash install/install_mac.sh                                          # 맥 (Apple Silicon)
powershell -ExecutionPolicy Bypass -File install\install_win.ps1     # 윈도우
```

아래는 스크립트가 무엇을 하는지, 손으로 할 때 어떻게 하는지다.

## 준비물
- 맥: Apple Silicon(M1 이상). 블렌더 5.2 맥판은 Apple Silicon용만 나온다.
- 윈도우: 윈도우 10/11 64비트. `winget`(Microsoft Store 의 '앱 설치 관리자')이 있으면 쓰고, 없어도 설치 스크립트가 공식 zip 으로 대신 깐다. 렌더에 엔비디아 그래픽카드를 쓰면 드라이버 575 이상(5.2 의 OptiX 최소 조건).
- 디스크 1GB 정도.

## 왜 5.2.3 인가
- 5.2 는 LTS 라 2028년 7월까지 버그 고침이 나온다. 5.1 은 2026년 7월에 지원이 끝났다.
- 이 저장소의 코드·시험은 전부 5.2.3 에서 돌렸다. 버전이 다르면 대부분 돌지만, 맥·윈도우가 렌더를 나눌 때는 **두 기기 버전이 꼭 같아야 한다**(06 문서).

## 단계

### 맥
스크립트는 공식 서버에서 dmg 를 받아 **공식 sha256 해시와 맞는지 확인한 뒤** `/Applications` 에 넣는다.
손으로 하려면:

```bash
curl -fLO https://download.blender.org/release/Blender5.2/blender-5.2.3-macos-arm64.dmg
curl -fsSL https://download.blender.org/release/Blender5.2/blender-5.2.3.sha256 | grep macos
shasum -a 256 blender-5.2.3-macos-arm64.dmg      # 위 줄의 값과 같아야 한다
open blender-5.2.3-macos-arm64.dmg               # Blender.app 을 응용 프로그램 폴더로 끌어 넣기
```

이미 다른 버전(예: 5.1)이 `/Applications/Blender.app` 에 있으면 스크립트는 그걸 지우지 않고 `/Applications/Blender 5.2.app` 으로 나란히 깔고, `studio` 에 그 경로를 알려 준다.

### 윈도우
```powershell
winget install --id BlenderFoundation.Blender -e --version 5.2.3
```
`C:\Program Files\Blender Foundation\Blender 5.2\blender.exe` 에 깔린다.

설치 스크립트는 블렌더를 이 순서로 찾고, 없을 때만 새로 깐다: `-BlenderPath` → 전에 `studio config blender_path` 로 알려 준 경로 → 환경변수 `BLENDER_PATH` → `Program Files` → `-BlenderDir`(기본 `%LOCALAPPDATA%\Programs\Blender`) → `PATH`. 버전이 5.2 가 아니면 건너뛴다.
**winget 이 없으면**(관리자 계정·서버판 등) 공식 zip(포터블) `blender-5.2.3-windows-x64.zip` 을 download.blender.org 에서 받아 **공식 sha256 과 맞는지 확인한 뒤** `-BlenderDir` 에 푼다. 관리자 권한이 필요 없다.
```powershell
powershell -ExecutionPolicy Bypass -File install\install_win.ps1 -BlenderPath "D:\Blender\blender-5.2.3-windows-x64\blender.exe"   # 이미 있는 것
powershell -ExecutionPolicy Bypass -File install\install_win.ps1 -BlenderDir "D:\Apps\Blender"                                      # 새로 받을 곳
```

## 확인
```bash
/Applications/Blender.app/Contents/MacOS/Blender --version        # 맥
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --version   # 윈도우
```
`Blender 5.2.3 LTS` 가 나오면 끝. `studio` 를 설치했다면(02 문서) `studio status` 의 `blender` 항목에도 나온다.

블렌더 위치가 특이하면 알려 준다:
```bash
studio config blender_path "/경로/Blender"
```

## 백그라운드 실행 — 알아 두면 편한 것
GUI 를 안 띄우고 스크립트만 돌릴 수 있다. 렌더·대량 작업은 이쪽이 빠르고 안전하다.

```bash
Blender -b 장면.blend -P 스크립트.py -- 스크립트인자
```
- 순서가 중요하다: `-b`(백그라운드) → 파일 → `-P`(파이썬). `--python-exit-code 1` 을 붙이면 스크립트 오류가 종료 코드로 나온다.
- `studio` 는 블렌더 GUI 가 꺼져 있으면 이 방식으로 **작업 장면**(`~/.blender-mcp-studio/work/scene.blend`)을 열어 고치고 저장한다.

## 자주 막히는 곳
| 증상 | 원인 · 해결 |
|---|---|
| 설치 뒤 첫 Cycles 렌더가 2분 넘게 멈춘 것 같다 | 맥 GPU 커널을 처음 만드는 중이다(실측 149초). 두 번째부터 30초 안팎. 기다리면 된다. |
| 새 버전을 처음 열 때 '이전 버전 설정 가져오기'가 안 나온다 | 새 버전 설정을 먼저 저장해 버리면 그 질문이 사라진다. 설치 스크립트는 그래서 처음 여는 버전이면 애드온 켜기를 미루고 "한 번 열어 주세요"라고 안내한다. |
| 옛 스크립트가 5.2 에서 `KeyError`·`TypeError` | 5.2 에서 지오메트리 노드 모디파이어 입력이 `md["Socket_2"]` → `md.properties.inputs.Socket_2.value` 로 바뀌었다. Random Value·Compare 노드 소켓 번호도 바뀌었으니 이름으로 찾는다. |
| 5.0 이후 `action.fcurves` 가 없다 | 채널백을 쓴다: `bpy_extras.anim_utils.action_get_channelbag_for_slot(action, slot).fcurves`. 합성 노드는 `scene.node_tree` 대신 `scene.compositing_node_group`. |
| 백그라운드에서 블렌더가 죽는다 | `-b` 에서는 조각(Sculpt) 모드 연산자를 쓰지 않는다. bpy 컬렉션에 `[::2]` 같은 건너뛰기 슬라이스도 안 된다(`range` 로). |
| 노드를 이름으로 못 찾는다 | UI 언어(한글)에 따라 노드 이름이 바뀐다. `node.type` 으로 찾는다. |
| 윈도우에서 OptiX 가 안 보인다 | 엔비디아 드라이버 575 이상으로 올린다. |
| 윈도우 설치 스크립트가 "스마트 앱 컨트롤이 켜져 있습니다" 로 멈춘다 · 블렌더가 아무 말 없이 안 뜬다(종료 코드 0xC0E90002) · `uvx` 가 `os error 4551`(애플리케이션 제어 정책에서 이 파일을 차단) | 새로 설치한 윈도우 11 의 **스마트 앱 컨트롤**이 서명 없는 프로그램 조각을 막는다. 블렌더 5.2.3 공식판에 든 DLL 61개와 uv 가 받는 파이썬이 모두 서명이 없어 걸린다(윈도우 샌드박스에서 실측). 이 도구를 쓰려면 윈도우 보안 > 앱 및 브라우저 컨트롤 > 스마트 앱 컨트롤 설정에서 끄는 수밖에 없다. 보안 수준을 낮추는 일이고, 윈도우 버전에 따라 다시 켜려면 윈도우를 새로 설치해야 할 수 있으니 직접 판단한다. 상태 확인: `(Get-ItemProperty HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy).VerifiedAndReputablePolicyState` — 0 꺼짐 · 1 켜짐 · 2 평가(막지 않음). |
