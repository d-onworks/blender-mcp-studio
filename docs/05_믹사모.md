# 05. 믹사모 — 무료 자동 리깅과 동작 가져오기

> "이 캐릭터에 펀치 동작 넣어 줘" 한마디로: 리그 없는 캐릭터는 믹사모(어도비, 무료)에 올려 뼈대를 붙이고(마커는 자동으로 찍는다), 동작을 받아 캐릭터에 액션으로 굽는다. 이미 믹사모 뼈대인 캐릭터는 동작만 더한다.

## 준비물
- 02·03 문서까지 끝
- 어도비 계정(무료) — 믹사모는 어도비 로그인으로 쓴다. **검색도 로그인해야 된다**(2026-10 부터)
- 두 발로 선 사람형 캐릭터 메시, **T자 또는 A자 자세**(팔을 몸에 붙인 I자는 안 된다). 네 발 동물·물건은 믹사모가 리깅하지 못한다

## 단계

### 1. 계정 연동(한 번만, 토큰은 하루 뒤 만료)
```bash
studio account signup mixamo     # mixamo.com 열기 — 어도비 계정이 없으면 여기서 가입
studio account login mixamo      # 로그인 창 → 어도비 로그인만 하면 접속 토큰을 잡아 저장
```
- 로그아웃 상태면 창이 사이트의 'Log in' 을 대신 눌러 어도비 로그인 화면까지 데려간다. 이메일·비밀번호는 직접 넣는다. **"Protect your account…(2단계 인증 권유)" 화면은 'Remind me later' 로 넘겨도 된다.**
- 토큰은 약 **24시간** 뒤 만료된다. 결과의 `hours_left` 가 남은 시간이다. 1시간 넘게 남았으면 창을 다시 열지 않는다. 만료 뒤에는 다시 `login`(영구 프로필이라 보통 클릭 한 번).
- 토큰 값은 어디에도 출력되지 않는다(`~/.blender-mcp-studio/credentials.json`, 권한 600).
- 손으로 넣을 때: mixamo.com 로그인 → 개발자 도구(F12, 맥 ⌥⌘I) → Console 에 `localStorage.access_token` → 따옴표 안 값을 `studio account login mixamo --token-stdin` 에 붙여 넣기.

### 2. 클로드에게 시키기
```
사용자: 펀치 동작 뭐 있어?
클로드: (mixamo_search "punch") → 번호 붙은 썸네일 시트를 보여 준다
사용자: 2번을 Hero 에 넣어 줘
클로드: (mixamo_animate "Hero", "2")
        → Hero 에 뼈대가 없으면 먼저 자동 리깅(약 30~60초) → 동작을 받아 'Punch_Combo' 액션으로 굽는다
사용자: 걷기도. 제자리로
클로드: (mixamo_animate "Hero", "walking", in_place=True)
사용자: 뭐 붙였지?
클로드: (mixamo_list_applied)
```
터미널도 같다:
```bash
studio mixamo search punch
studio mixamo rig Hero                 # 리깅만 따로 할 때
studio mixamo animate Hero "Cross Punch"
studio mixamo animate Hero walking --in-place
studio mixamo list
```
- `motion` 에는 검색어("punch"), 동작 이름("Cross Punch"), 마지막 검색의 번호("2"), 동작 id 를 줄 수 있다. 이름이 같으면 정확히 같은 이름 → 설명이 같은 것 → 이름에 포함된 것 → 첫 결과 순으로 고르고, 나머지 후보는 결과의 `other_candidates` 에 나온다.
- 받은 FBX 는 `~/.blender-mcp-studio/mixamo/` 에 쌓인다(같은 동작을 또 쓰면 다시 받지 않는다). 저장소에는 넣지 않는다.

## 안에서 일어나는 일

### 자동 리깅(`mixamo_rig`)
1. 캐릭터 메시(빈 물체를 주면 그 아래 메시 전부)를 하나로 합친 **복사본**을 만든다. 이미 리그가 있으면 쉬는 자세로. 원본은 건드리지 않는다.
2. **정면 판단**: 발끝이 나온 쪽을 정면으로 본다. 블렌더 정면(-Y)이 아니면 180° 돌려 올리고, 돌아올 때 되돌린다.
3. **마커 자동 추정**(턱·양 손목·양 팔꿈치·양 무릎·사타구니 8개) — 메시 모양을 잰다.
   - 사타구니: 다리 사이 틈이 시작되는 높이 / 겨드랑이: 가슴 높이 단면에서 몸통 끝 / 팔꿈치·손목: 겨드랑이→손끝의 40%·76% / 무릎: 사타구니→바닥의 58% / 턱: 머리에서 가장 넓은 곳 아래로 폭이 60% 밑으로 줄어드는 곳
   - 마커를 찍은 정면 그림이 결과의 `marker_preview` 에 나온다. **클로드는 이 그림을 보고** 이상하면 고친 마커로 다시 리깅할 수 있다.
4. 믹사모에 FBX 업로드 → 웹 뷰어가 보는 모델 경계를 받아 우리 계산과 맞는지 검산(어긋나면 마커를 그 비율로 옮김) → 자동 리깅 요청(대칭 켬, 뼈대 Standard 65) → 살+뼈대 FBX(원래 자세) 내보내기.
5. 블렌더로 가져와 **크기 1배·회전 0** 으로 정리(믹사모 FBX 는 아마추어가 0.01배·90° 회전이라 그대로 두면 100배·누움 사고가 난다), 원본 경계에 크기·위치를 맞추고 원점을 발밑 가운데에 둔다. 재질은 원본에 같은 이름이 있으면 원본 것으로. 원본 메시는 숨긴다(지우지 않음). 이름은 아마추어 `<이름>_rig`.

고급 옵션(MCP 도구·터미널 같음): `mixamo_rig(이름, markers={...}, skeleton="standard"|"3chain"|"2chain"|"nofingers", facing="auto"|"-Y"|"+Y")`
```bash
studio mixamo rig Hero --skeleton nofingers --facing +Y --markers '{"chin": [0, 1.52], "groin": [0, 0.92]}'   # 또는 --markers 고친마커.json
studio mixamo animate Hero punch --fps 24 --action-name Hero_Punch
studio mixamo animate Rigify캐릭터 walking --mapping 짝표.json                                             # 믹사모 뼈 이름이 아닌 리그
```
- MCP 로 부르면 `mixamo_rig` 는 마커를 찍은 정면 그림, `mixamo_search` 는 썸네일 시트를 **그림으로 함께** 돌려준다(클로드가 바로 보고 사용자에게 보여 준다).
- `markers` = `{"chin": [x, z], "larm": [x, z], …}` — 정면에서 본 **x = 몸 가운데 기준 좌우(m, 화면 왼쪽이 -), z = 발바닥 기준 높이(m)**. 결과의 `markers_blender` 와 같은 기준이라 그 값을 고쳐 넣으면 된다.

### 동작 붙이기(`mixamo_animate`)
1. 대상(아마추어·메시·빈 물체 이름)에서 리그를 찾는다. 없으면 `mixamo_rig` 부터.
2. 리그가 믹사모 뼈 이름(`mixamorig:*`)이 아니면 짝표 `mapping={"Hips": "pelvis", "LeftArm": "upperarm_l", …}` 가 필요하다(키 = 접두어 뗀 믹사모 이름).
3. 동작을 **뼈대만** FBX 로 받는다 — 우리가 리깅한 캐릭터면 그 캐릭터 기준(비율이 같아 발 미끄러짐이 적다), 아니면 X Bot 기준.
4. **'쉬는 뼈 × 바뀐 만큼'** 방식으로 옮겨 액션으로 굽는다. 쉬는 자세(T·A)·뼈 축·아마추어 크기(0.01배 그대로여도)가 달라도 같은 결과. 30fps 동작은 장면 fps(예: 24)로 **시간 기준** 다시 샘플한다. 엉덩이 이동은 엉덩이 높이 비율로 줄이거나 늘린다.
5. `in_place=True`: 믹사모가 제자리 옵션을 지원하는 동작(걷기·달리기)은 믹사모에서, 아니면 블렌더에서 엉덩이 앞뒤·좌우 이동을 지운다. 결과의 `hips_travel_m`(처음→끝 수평 이동)으로 확인.
6. 액션은 가짜 사용자(fake user)로 남아 여러 개를 쌓을 수 있고, 마지막에 붙인 것이 활성이다. 장면 끝 프레임을 그 길이에 맞춘다.

## 확인
- 결과에 액션 이름·프레임 수·옮긴 뼈 수(`mapped_bones`, 빠진 뼈 `unmapped_count`)가 나온다.
- `studio screenshot` 으로 동작 중간 프레임을 한 장 찍어 본다(또는 GUI 에서 재생).
- 렌더 전에 손목·팔꿈치·무릎에 Motion Paths(궤적)를 켜서 튀는 프레임이 없는지 본다.

## 라이선스
- 믹사모 캐릭터·동작은 개인·상업·비영리 작품(영상·게임·일러스트·3D 프린트)에 **로열티 없이** 쓸 수 있다(어도비 FAQ).
- 작품에 넣지 않은 **원본 FBX 를 그대로 묶어 배포·판매하는 건 허용 목록에 없다** → 저장소에 커밋하지 않는다(`.gitignore` 가 `*.fbx`·`assets/` 를 막는다).
- 업로드한 캐릭터는 믹사모 계정의 캐릭터 목록에 남는다.
- `studio` 가 쓰는 믹사모 API 는 웹사이트가 쓰는 비공식 API 다. 어도비가 바꾸면 예고 없이 깨질 수 있다.

## 자주 막히는 곳(실제로 겪은 것)
| 증상 | 원인 · 해결 |
|---|---|
| "믹사모 접속 토큰이 만료됐거나 틀렸습니다(HTTP 401/403)" | 하루가 지났다. `studio account login mixamo`. 검색도 로그인이 필요하다 |
| "자동 리깅이 두 번 다 실패했습니다" | 같은 몸·마커도 믹사모 쪽에서 가끔 한 번 실패한다(시험 9번 중 1번) — 그래서 같은 캐릭터로 한 번은 저절로 다시 한다(결과 `marker_fit.rig_attempts`). 두 번 다 실패하면 마커가 몸 밖이거나 자세가 T·A 가 아니다. 결과에 나온 마커 그림을 보고 `markers` 로 고쳐 다시. 팔을 몸에 붙인 I자는 블렌더에서 팔을 들어 T·A 로 만든 뒤 |
| 경고 "다리 사이 틈을 못 찾았습니다" | 다리가 붙었거나 치마·긴 옷. 사타구니를 비율로 찍었으니 그림을 확인. 다리를 조금 벌리면 정확해진다 |
| 칼·방패·큰 장식이 엉뚱하게 늘어난다 | 몸에서 먼 물체는 믹사모 자동 가중치가 틀린다. **무기·소품은 떼어 두고 리깅한 뒤 손 뼈에 붙인다**(Child Of 제약 또는 뼈 부모) |
| 손가락 뼈가 없다(`finger_bones` 0) | 손이 뭉툭하면 믹사모가 손가락을 못 찾는다. 손가락을 몇 도씩 벌려 두거나 `skeleton="nofingers"` |
| 발이 안쪽·바깥으로 20~30° 꺾인다 | 뼈마다 '월드 회전 그대로 복사'(COPY_ROTATION) 방식의 한계. 이 도구는 **'내 쉬는 뼈 × 믹사모가 바뀐 만큼'** 으로 옮겨 이 문제가 없다 |
| 작은 캐릭터가 성큼성큼 미끄러진다 | 엉덩이 이동을 '엉덩이 높이 비율'로 줄인다(자동, 결과 `hip_scale`). 그래도 제자리 동작이 0.3~3cm/프레임 밀리면 발 IK 로 고정(1cm 이하는 화면에서 안 보임) |
| 큰 머리 캐릭터의 손이 머리를 뚫는다 | 믹사모 동작은 사람 비율(X Bot) 기준이다. 머리가 크면 가드 손이 머리 안으로 들어간다 → 손을 턱 아래로 내리는 보정. 얼굴을 가리는 동작은 못 쓴다 |
| 주먹이 상대에게 안 닿는다 | 팔이 짧으면 뻗는 거리가 짧다(실측 0.45~0.6m). 맞는 순간 상대를 그 거리로 끌어오는 게 자연스럽다 |
| 30fps 동작을 24fps 장면에 넣으니 빨라진다 | 이 도구는 시간 기준으로 다시 샘플한다(자동). 직접 가져올 땐 프레임 번호가 아니라 시간으로 |
| 검색해도 원하는 동작이 안 나온다 | 믹사모 검색은 한 번에 24개까지라 **검색어는 짧게**("cross punch" O, 설명 전체 X) |
| In Place 가 믹사모에서 안 먹는다 | 걷기·달리기처럼 이동이 있는 동작만 지원 → 이 도구가 블렌더에서 대신 지운다(결과 `note`) |
| GUI 블렌더에서 하다 멈춘 것 같다 | 리깅은 믹사모 서버 작업이라 30~60초 걸린다. 같은 명령을 바로 다시 보내지 말고 기다린다 |

## 믹사모 말고(대안)
| 도구 | 장점 | 주의 |
|---|---|---|
| Rigify(블렌더 내장) | 얼굴·IK·조종판까지 영화용 리그 | 손이 많이 간다. 믹사모 동작은 짝표(`mapping`)로 옮긴다 |
| Make-It-Animatable(오픈, MIT) | 믹사모 뼈 이름 그대로 뼈대·가중치를 1초 만에. A자·포즈 잡힌 메시도 | 엔비디아 GPU·리눅스(WSL) 권장. 결과는 `mixamo_animate` 로 바로 동작을 붙일 수 있다 |
| AccuRIG 2(무료, 윈도우) | 옷·소품 든 캐릭터에 강하다고 소개 | 직접 시험 필요 |
| Tripo 리깅(유료 API) | 설치 없이 믹사모 이름으로 30초 | 크레딧 과금, 가중치 보정은 블렌더에서 |
