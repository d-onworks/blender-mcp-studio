# 04. 스케치팹 에셋 가져오기

> "자동차 찾아줘" 한마디로 쓸 만한 무료 모델을 추천받고, 고른 걸 블렌더 장면에 크기·바닥까지 맞춰 넣고, 출처 표기 문구까지 남긴다.

## 준비물
- 02·03 문서까지 끝
- 스케치팹 계정(무료) — 검색은 계정 없이 되고, **다운로드에 API 토큰이 필요**하다

## 단계

### 1. 계정 연동(한 번만)
클로드에게 "스케치팹 연동해 줘" 라고 하거나 터미널에서:
```bash
studio account signup sketchfab     # 가입 페이지 열기(계정이 없을 때)
studio account login sketchfab      # 로그인 창이 열린다 → 로그인만 하면 토큰을 찾아 저장
```
- 로그인 창은 `~/.blender-mcp-studio/browser-profile` 영구 프로필이라 다음엔 로그인 상태로 열린다.
- 창에서 토큰을 못 찾으면: sketchfab.com → Settings → **Password & API** → API Token 복사 →
  `studio account login sketchfab --token-stdin` 에 붙여 넣기(화면·명령 기록에 안 남는다).
- 토큰은 `~/.blender-mcp-studio/credentials.json`(권한 600)에만 저장되고, 어떤 출력에도 값이 나오지 않는다("저장 파일/없음"만).
- 환경변수 `SKETCHFAB_API_TOKEN` 이 있으면 그걸 먼저 쓴다(임시 시험용).

### 2. 찾기
```
사용자: 자동차 찾아줘
클로드: (sketchfab_search "car") → 썸네일 시트를 보여 주며 "1번 Cartoon Sports Car(CC BY, 면 1.9만)…"
```
터미널:
```bash
studio sketchfab search "sports car" --count 8
studio sketchfab search "chair" --license cc0 --max-faces 50000
studio sketchfab search "robot" --animated --rigged
```
- **다운로드 가능한 모델만** 받아 추천 점수(0~100)로 줄 세운다:
  검색어와 맞는 정도(스케치팹 순위) 25 · 라이선스 쓰기 쉬움 30 · 좋아요 20 · 조회수 8 · 면 수 적당함 12 · 스태프 추천 5.
- 결과마다 번호·이름·작성자·라이선스(초록 = 상업 가능, 빨강 = 비상업)·면 수·좋아요·조회수가 적힌 **콘택트시트 PNG** 를 만든다
  (`~/.blender-mcp-studio/cache/sketchfab/search_*.png`). MCP 로 부르면 그림이 바로 대화에 뜬다.
- 검색어는 영어가 결과가 훨씬 많다. 클로드는 "자동차" → "car" 처럼 바꿔 검색한다.

### 3. 가져오기
```
사용자: 3번 가져와, 길이 4.5미터로
클로드: (sketchfab_import "3", target_size_m=4.5)
```
터미널:
```bash
studio sketchfab import 3 --size 4.5            # 마지막 검색의 3번
studio sketchfab import 0fd87559642a41b7a7924876ad3e9399
studio --headless sketchfab import 3            # GUI 가 켜져 있어도 백그라운드 작업 장면에
```
하는 일:
1. glb 를 받아 `~/.blender-mcp-studio/assets/sketchfab/<이름>_<uid8>/model.glb` 에 둔다(다시 가져올 땐 안 받음).
2. 블렌더로 불러와 `Sketchfab_<이름>` 컬렉션에 모으고, 빈 물체 `<이름>` 아래에 묶는다 — **이 손잡이만 옮기고 돌리고 키우면 된다.**
3. `target_size_m` 을 주면 가장 긴 변이 그 길이가 되게 맞추고, 바닥(Z=0) 가운데에 놓는다.
4. 출처를 남긴다: 모델 폴더 `credits.json`, 작업 전체 목록 `~/.blender-mcp-studio/work/credits.json`, 블렌더 텍스트 블록 `CREDITS`, 컬렉션 속성 `credit`.

GUI 블렌더가 켜져 있으면 그 장면에, 꺼져 있으면 백그라운드 작업 장면(`~/.blender-mcp-studio/work/scene.blend`)에 들어간다.

## 확인
```bash
studio screenshot        # 장면 한 장 → 경로가 나온다(MCP: blender_screenshot 는 그림을 바로 보여 준다)
```
실제 시험(2026-10-28): "sports car" 검색 → 1번 Cartoon Sports Car 가져오기(11초, 4.5m) → 백그라운드 워크벤치 렌더로 바닥 위에 텍스처까지 들어간 것 확인.

## 라이선스와 출처 표기
| 라이선스 | 상업 사용 | 출처 표기 | 메모 |
|---|---|---|---|
| CC0 | O | 필요 없음 | 가장 편하다 |
| CC BY | O | **필수** | 수익 영상에도 OK, 설명란에 문구 |
| CC BY-SA | O | 필수 | 고친 모델을 배포하면 같은 라이선스로 |
| CC BY-ND | O | 필수 | 모델을 고쳐서 배포 금지(영상에 쓰는 건 보통 OK) |
| CC BY-NC 계열 | **X** | 필수 | 수익 영상·광고 금지 |
| Standard / Free Standard | O | 필요 없음 | 스케치팹 스토어 약관 |
| Editorial | X | 필수 | 보도용 |

가져올 때 결과의 `credit_line` 을 영상 설명란에 그대로 붙인다:
```
"Cartoon Sports Car" by RCC Design (https://sketchfab.com/3d-models/cartoon-sports-car-0fd87559642a41b7a7924876ad3e9399) is licensed under CC Attribution (http://creativecommons.org/licenses/by/4.0/)
```
받은 모델 파일은 저장소에 커밋하지 않는다(`.gitignore` 가 막는다). 라이선스가 허락해도 저장소는 코드만 둔다.

## 자주 막히는 곳
| 증상 | 원인 · 해결 |
|---|---|
| "API 토큰이 없습니다" | `studio account login sketchfab`. `studio status` 의 `accounts.sketchfab` 가 "저장 파일" 이면 된 것. |
| HTTP 401 | 토큰이 바뀌었다(스케치팹에서 재발급하면 옛 것은 무효). 다시 로그인. |
| HTTP 403 | 다운로드가 막힌 모델(작가 설정)이거나 스토어 유료 모델. 다른 걸 고른다. |
| 크기가 생각보다 작다 | 모델에 바닥판·받침이 붙어 있으면 그것까지 '가장 긴 변'에 들어간다. 손잡이 물체 크기를 직접 키우거나 받침 물체를 지운다. |
| 면 수가 '?' | 작가가 값을 안 올렸다. 추천 점수에서는 중간값으로 친다. |
| 백만 면 넘는 모델이 무겁다 | `--max-faces 150000` 처럼 상한을 둔다. 실사 스캔 모델은 수백만 면이 흔하다. |
| 받기 주소 만료 오류 | 스케치팹이 주는 받기 주소는 몇 분 뒤 만료된다. 다시 시키면 새로 받는다. |
| 질감이 바래 보인다 | 불러온 뒤 질감 색 공간: Base Color·Emission 만 sRGB, 거칠기·금속·노멀은 Non-Color. glb 는 보통 맞게 들어온다. |
| 애드온 패널의 'Use Sketchfab' 와 뭐가 다른가 | 애드온 방식도 된다(키를 패널에 넣음). 다만 그 키는 .blend 에 같이 저장되고, 추천 점수·콘택트시트·출처 기록은 없다. |
