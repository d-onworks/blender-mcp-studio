# 스레드 글 초안 3개

추천: **2번**. 첫 줄에 받을 것(무료 공개)이 바로 보이고, 목록이 깃헙 README 순서(설치 → 스케치팹 → 믹사모 → 분산 렌더)와 같아서 링크로 넘어가기 쉽다.

## 1
예전에 3D 하는 후배가 그랫다
”블렌더는 단축키 외우다 1년 간다“
그 말 듣고 나는 입구에서 돌아섰음
근데 9월26일부터 클로드 코드에 블렌더 MCP 붙여서 캐릭터, 리깅, 애니, 렌더까지 말로만 시켰다
”자동차 찾아줘“ 하면 스케치팹 추천 썸네일 띄워주고 고르면 블렌더로 가져옴
“펀치 동작 넣어줘” 하면 믹사모로 자동리깅해서 붙인다
렌더는 맥이랑 윈도우 그래픽카드 나눠 돌려서 1.59배 빨라짐
지시 348번, 모델링은 손으로 한번도 안했다
그냥 면허 따기 전에 대리기사부터 부른 셈
설치는 프롬프트 한장 붙여넣기, 깃헙에 무료로 다 풀었다
사람 머리카락 7번 실패한것까지 적어둠
이제 1년 걸리는 건 단축키가 아니라 머리카락이다

## 2
블렌더 단축키 하나 몰라도 3D 캐릭터 뽑는법 깃헙에 무료로 풀었다
블렌더 MCP + 클로드 코드로 캐릭터, 리깅, 애니, 렌더까지 전부 말로만 시킨 과정임
- 설치는 프롬프트 한 장 붙여넣기면 끝
- “자동차 찾아줘” → 스케치팹 추천 모델 썸네일 뜸 → 고르면 블렌더로 가져옴
- “펀치 동작 넣어줘” → 믹사모 자동 리깅해서 붙여줌
- 맥+윈도우 그래픽카드 나눠서 렌더하니 1.59배 빨라짐
9월26일부터 지시 348번, 모델링은 손으로 한번도 안했다
아 사람 머리카락은 7번 실패했고 그것도 그대로 적어둠
3D 학원 결제버튼 누르기전에 이거부터 받아라

## 3
블렌더 단축키 외우는 시대는 끝났다
9월26일부터 블렌더 MCP에 클로드 코드 붙여서 말로만 348번 시켰다. 캐릭터, 리깅, 애니, 렌더까지 다 뽑앗고 모델링은 손으로 한 번도 안 함.
”자동차 찾아줘“ 하면 스케치팹 추천 모델 썸네일 띄워주고 고르면 블렌더로 가져옴
“펀치 동작 넣어줘“ 하면 믹사모로 자동리깅해서 붙여줌
맥이랑 윈도우 그래픽카드 나눠 돌리니 렌더도 1.59배 빨라졌다.
사람 머리카락만 7번 실패해서 멘탈 개갈림, 그것까지 그대로 적어서 깃헙에 무료로 풀었다
설치는 프롬프트 한 장 붙여넣기면 끝
블렌더는 이제 배우는 툴이 아니라 시키는 툴이다.

## 사실 확인 메모
- 348번·9/26 시작 = 제작 일지 자동 집계(9/26~10/22). 1.59배 = 1분 시네마틱 1,164장 한 건의 실측(README 5절).
- "블렌더 단축키 하나 몰라도"는 과장 소지 — 대표가 블렌더 화면을 휠로 돌린 기록이 있다. 올릴 때 판단.
- 깃헙 링크(https://github.com/d-onworks/blender-mcp-studio)는 공개 뒤에 붙인다.
